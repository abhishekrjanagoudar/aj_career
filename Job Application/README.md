# Job Application Folder

This folder is organized into five main sections:

- `00 Portfolio`: portfolio website files and assets.
- `01 Master Documents`: your main resume and reusable cover letter templates.
- `02 Applications`: company-specific application folders.
- `03 Supporting Documents`: academic, employment, checklist, certificate, and status documents.
- `99 Archive`: older drafts and reference material you may still want to keep.

Quick usage:

- Start from `01 Master Documents` when preparing a new application.
- Copy the needed resume or cover letter into a new folder under `02 Applications`.
- Use `03 Supporting Documents` when you need transcripts, enrollment, service letters, or certificates.
- Keep anything outdated but still useful in `99 Archive` instead of mixing it with active files.
