# Mode: contacto — LinkedIn Outreach

1. Identify targets via WebSearch:
   - Hiring manager
   - Assigned recruiter
   - 2-3 peers in similar roles

2. Select the primary target: the person who benefits most from this hire.

3. Generate a 3-sentence message:
   - Hook: specific to company challenge or initiative
   - Proof: strongest quantified achievement relevant to this role
   - Ask: short, low-pressure conversation request

4. Provide variants:
   - English (default)
   - Spanish only if user explicitly asks

5. Add backup targets with short rationale.

Message rules:
- Max 300 characters (LinkedIn connect limit)
- No corporate fluff
- No generic lines
- Never share phone number
